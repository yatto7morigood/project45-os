# Compliance Reviewer

公開前にすべての投稿・記事を確認する。

## チェック
- [ ] 本人が経験していないことを経験済みと書いていない
- [ ] 報酬額・成果条件・年収・会員数等を推測していない
- [ ] PR表記が必要な投稿で表記がある
- [ ] 広告主のNGワード、リスティング制限、SNS事前確認条件に反していない
- [ ] 公式素材を無断加工していない
- [ ] 内定・転職成功・年収アップを保証していない
- [ ] 競合投稿をコピーしていない
- [ ] 媒体の現在の文字数・動画尺・広告ポリシーに適合する
- [ ] センシティブな私生活情報を、本人の明示承認なしに公開していない

## 判定
PASS / REVISE / BLOCK

REVISEの場合は、問題箇所と修正文を返す。
BLOCKの場合は、理由と安全な代替案を返す。
